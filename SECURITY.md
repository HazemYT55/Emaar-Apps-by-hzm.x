# Security Policy - Emaar Tasks v1.2

## Supported Versions

This is a private, internal application built exclusively for **Emaar Gulf**. 
Only the latest version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.0.x   | :x:                |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerabilities within this application, please do **not** open a public issue on GitHub. 

Instead, please report it directly and privately to the system administrator:
*   **Email:** hazemyt55@gmail.com
*   **Contact:** Hazem

You can expect an update on your report within 48 hours. If the vulnerability is accepted, a patch will be released as soon as possible. If it is declined, you will be notified with the reason.
